2.2. 使用するパーツ等について

　走行体は本手順書に従って、3.1 で指示のある組立図中 2.4. で示すダミーウェイトおよび

2.5. で示す右上 A-B ピラージョイントを除き、パーツの過不足なく組み立てなければいけません。

　走行体に使用する LEGO®  Education  SPIKE ™  プライムセットおよび LEGO® パーツは市販
されているものをそのまま使用するものとし、パーツの加工や改造などは禁止します。

2.3. 走行体への装飾、および禁止事項について

　走行体に、装飾やケーブル固定を目的とした若干の部品の追加は、下記禁止事項に該当しない

範囲で可能とします。

• 走行体への禁止事項：

 ■ 2.1 で示すパーツ等構成物を分解・改造・加工する行為。ただし、単に SPIKE 本体の接触不

良を起こしたコネクタを修理するためだけに行われた改造・加工行為は例外として認める。

 ■ 接着剤等を使用してパーツ同士を固着させる行為。

 ■ 落ちやすい塗料の使用やグリスアップ、落下物が生じる恐れのあるものなど、コースを汚損

する恐れのある装飾。

 ■ 宣伝めいた内容の装飾。ただし、チーム名、公開所属名またはそれに類するもの（公開所属

の会社名 / 学校名及びロゴマーク・製品サービス名・キャッチコピー・スローガンなど）を

記載することは可能とする。

 ■ レンズやミラーなど、カメラ・SPIKE 本体・センサー・モーターの性能に影響を与える装飾。

 ■ ゴム・紐・結束バンド等を用いて車体強度等の向上を図る行為。ただし、単にケーブルの固

定を行うもの等、構造や性能に影響を与えない範囲での使用は可能とする。

 ■ カメラ・カラーセンサー・アーム・キャスターボール・タイヤのゴムに対する装飾。

 ■ 組立図に従って組み上げられた各走行体の全幅・全長を超える装飾。なお、通信・電源・カ

メラの USB ケーブルは装飾品ではなく走行体の一部であるためこの限りではない。

 ■ 電飾など、相手の走行を妨害する恐れのある装飾。

 ■ コース上の難所等と直接接触する装飾

×

2.5. 使用するバッテリーについて

　大会当日、適正なバッテリーを装着していることが各大会の車検担当者または審判によって確

認された車検後、装着したバッテリーを取り外したり交換したりしてはいけません。

　バッテリーを取り外さず AC アダプタや USB ケーブルなどを走行体へ直接接続して充電するこ

とは車検後も認められますが、取り外しての充電は認められません。

　SPIKE 本体および Raspberry Pi で使用するバッテリーについては以下の通りとします。

• SPIKE 本体：

 ■ 「LEGO® テクニック ラージハブ バッテリー」（SPK45610・キット同梱）に限る

アプライドのみ

• Raspberry Pi：

 ■ 105g 以上のモバイルバッテリー（エレコム EC-C12BK 推奨）

　Raspberry Pi 用モバイルバッテリーに関して、モーター上部のスペースに推奨バッテリーが搭

載されることを前提に走行体が設計されています。初代 SPIKE キットの 10000 バッテリーなど、

サイズの異なるものは搭載できない可能性もありますのでご了承ください。

　Raspberry  Pi 用推奨バッテリーは、公称 112g、実測 109g 程度です。車検時に 105g を割り

込んでいることが判明した場合は、養生テープなどを巻きつけて調整してください、1 巻き約 0.7g

程度になります。

　この推奨バッテリーを使用する場合など、2025 年までのものより一回り小さいモバイルバッ

テリーを搭載する場合は、P.115 の右上 A-B ピラージョイントを、黄色 L 字ビームから黒色 T 字

ビームに変更しても構いません。

どちらでも OK
