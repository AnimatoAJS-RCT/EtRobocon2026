# 超音波センサー特性評価

## 目的

`UltrasonicAlignTracer` の探索アルゴリズムを変更する前に、`UltrasonicProbeTracer` を用いて
PORT_F の超音波センサーを特性評価します。Probe は制御周期ごとにロボットを停止させ、
`pup_device_get_values()` の戻り値を直接ログへ出力します。

センサーの取付位置は大会規約で固定されています。これらの計測および大会本番の構成において、
センサーを上下その他の方向へ移動させないでください。

## Probe の実行

`tracer.ini` に Probe の行を1つ設定し、無関係な走行 Tracer はコメントアウトしてください。

```text
UltrasonicProbeTracer DISTL 300 100
```

書式は次のとおりです。

```text
UltrasonicProbeTracer <DISTL|DISTS|TRAW|ADRAW|ALL> <sample_count> [sample_interval_ms]
```

`sample_interval_ms` の既定値は 100 ms です。10 ms の制御周期単位へ切り上げられます。`ALL` は
DISTL、TRAW、ADRAW の順に読み取ります。モード切替ごとに 50 ms 待機し、1回読み捨ててから値を
記録します。このため `ALL` の1周期は指定したサンプル間隔より長くなります。実際の周期時間は
`[ULTRA_PROBE_CYCLE]` で確認してください。

Bluetooth 出力は PC 側に保存してください。記録値は1行1サンプルの TSV 形式です。

```text
[ULTRA_PROBE]\tseq\tmode\terr\tvalue\telapsed_ms
```

`err` は `pbio_error_t` の戻り値です。従って `err == 0, value == -1` は有効な距離を取得できなかった
センサー読取り値であり、`err != 0` は PUP 読取り失敗です。`[ULTRA_PROBE_CYCLE]` には、モード一巡ごとの
シーケンス番号と経過時間（ms）が出力されます。

## 計測

各条件で Bluetooth 出力を30秒以上記録してください。変化させる要因以外は、固定されたセンサー取付位置、
ロボット方位、ボトル姿勢、床面条件を実験記録に残してください。

| ID | 手順 | 記録する結果 |
| --- | --- | --- |
| E1 | ボトルを 200、300、400、500、600、800 mm に置き、静止状態で DISTL を測定します。 | 距離ごとの検出率ベースライン。 |
| E2 | 実施不可: 大会規約で取付位置が固定されているため、センサー高さ比較は除外します。対照記録が必要な場合だけ、同じ固定位置で E1 を繰り返します。 | 高さ比較を実施していないこと。 |
| E3 | E1 で有用だった各距離で `ALL` を実行します。 | DISTL が `-1` のときに TRAW または ADRAW が変化するか。 |
| E4 | 300 mm と 500 mm で DISTS を実行します。 | DISTL と比較した DISTS の検出率。 |
| E5 | 400 mm でモーターを停止したまま、操作者がロボットを -20 から +20 mm まで 5 mm 刻みで並進させ、各位置で DISTL を実行します。 | 並進位置による検出率の変動。 |
| E6 | 有用な固定距離でモーターを停止したまま、操作者がロボットを +/-60 度、35度/s で手動旋回させます。続けて 8 度刻み・各2秒静止の測定と比較します。 | 連続旋回と静止測定の検出率。 |
| E7 | 同じ距離でボトルを 40 mm 角の LEGO プレートに置き換え、DISTL を実行します。 | 平板に対するボトル固有の損失。 |

E3 と E6 を優先して実施してください。固定取付の規約により、E2 は Phase 2 の判断基準には使えません。

### Phase 1 の結論

- `-1` の由来: 全サンプルで `err == 0` だったため、PUPエラーではなくDISTLの無反射値。
- 弱いエコーに対する TRAW/ADRAW の有用性: 相関はあるが、Phase 2で距離判定へ使える水準とは判断しない。
- 連続旋回と静止測定の比較: 厳密な条件分離は未実施。手動走査中にも検出バーストが得られたため、連続旋回を暫定採用する。
- センサー取付位置: 大会規約に従い固定を維持する。
- Phase 2 の判断: DISTLの1-of-M判定、約35度/sの連続往復走査、方位占有ヒストグラムで開始する。

Phase 2 実機確認では、走査ログへ角度と走査方向を残し、連続旋回の検出率を再評価してください。
