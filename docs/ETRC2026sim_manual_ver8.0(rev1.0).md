1.1.1. Unityのシミュレーション性能について

• シミュレーション動作アプリケーションはUnityで作成されます

– 参考：Unity Player system requirements

https://docs.unity3d.com/Manual/system-requirements.html

• シミュレーションの3D描画はリアルタイム性を確保するため、

60FPSに設定しています (FPS:1秒間に描画されるコマ数)
– シミュレーションPCの3D描画性能が60FPSに満たないときは、

シミュレーション時間を実時間よりも遅くして60FPSを確保します

– シミュレーション時間と実時間比率をシミュレーターではTimeScaleとしています
– TimeScaleが1.00以下となった場合には物理演算結果が変わることにより、

タイヤのスリップや段差の通過時の挙動が変わる場合があります

– FPSとTimeScaleはシミュレーター画面で確認することができます ※スライド2.1参照

リアルタイムにFPSが更新されます
初期状態ではFPS固定モードで動作しています。

リアルタイムにTimeScaleが更新されます

1.2.2 シミュレータ向けPC環境の入手方法

• 高グラフィックス性能の入手方法を紹介します

GPU搭載PC・ゲーミングPC

最低予算：８万円程度
対象者：新規にPCを購入できる予算のある方
注意事項：推奨動作を満たしているか十分な確認が必要

グラフィックボード増設

最低予算：9000円程度
対象者：デスクトップ型PCのグラフィックス性能を強化されたい方
注意事項：増設スロットの空き、電源容量、補助電源ピン、ロープロファイル対応など

eGPU BOX(外付けGPUボックス)

最低予算： 4万5000円程度
対象者：ノート型PCのグラフィックス性能を強化されたい方
注意事項：Thunderbolt3の搭載が必須、BOXだけでなくグラフィックボードも必要

※いずれの方法も、中古品であれば更に安く入手できる場合があります。

また、PC環境の導入はETロボコン実行委員会ではサポート対象外です。
